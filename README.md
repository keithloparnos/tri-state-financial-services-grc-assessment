# tri-state-financial-services-grc-assessment
Cybersecurity Governance, Risk, and Compliance (GRC) assessment using NIST CSF 2.0 and ISO/IEC 27001.

## Project Overview

This project is a cybersecurity Governance, Risk, and Compliance (GRC) assessment developed for a fictional financial services organization, Tri-State Financial Services.

For this project, I worked through a GRC assessment from asset identification through risk assessment, control mapping, gap analysis, remediation planning, and an ISO/IEC 27001 Statement of Applicability.

The project uses the **NIST Cybersecurity Framework (CSF) 2.0** and **ISO/IEC 27001** as the primary reference frameworks.

---

## Objectives

- Identify and classify critical organizational assets
- Assess cybersecurity risks and vulnerabilities
- Develop a risk register
- Map identified risks to security controls
- Evaluate control gaps and desired security states
- Develop a remediation plan
- Create an ISO/IEC 27001 Statement of Applicability (SoA)
- Demonstrate practical GRC documentation and risk management skills

---

## Frameworks Used

### NIST Cybersecurity Framework (CSF) 2.0

Used to support cybersecurity risk identification, protection, detection, response, and governance activities.

### ISO/IEC 27001

Used to identify applicable information security controls and develop the Statement of Applicability.

---

## Project Components

### 1. Asset Inventory
Documents key organizational assets, including:

- Customer Database
- Employee Laptops
- Microsoft 365
- Network Firewall
- Customer Portal

Each asset was evaluated based on data sensitivity and business criticality.

### 2. Risk Register
Five cybersecurity risks were identified and assessed based on:

- Threat or vulnerability
- Potential impact
- Likelihood
- Overall risk level
- Existing controls
- Recommended treatment

### 3. Control Mapping
Identified risks were mapped to applicable security requirements using NIST CSF 2.0 and ISO/IEC 27001 controls.

### 4. Gap Assessment
The assessment compares the current security state against the desired state and identifies areas requiring additional controls or improvements.

### 5. Remediation Plan
Each identified gap includes:

- Remediation action
- Responsible owner
- Priority
- Target timeframe
- Status
- Success criteria

### 6. Statement of Applicability
Applicable ISO/IEC 27001 controls were documented with:

- Control ID
- Related risk
- Applicability
- Justification
- Implementation status
- Responsible owner
- Evidence/reference

---

## Key Findings

The assessment identified five high-level cybersecurity risks involving:

1. Unauthorized access to customer information
2. Lost or stolen employee laptops
3. Microsoft 365 account compromise
4. Firewall failure or misconfiguration
5. Customer portal vulnerabilities

The assessment identified control gaps requiring additional security measures, including stronger access controls, endpoint protections, multi-factor authentication, firewall configuration management, vulnerability scanning, and penetration testing.

---

## Remediation Approach

The remediation plan prioritizes the identified risks and establishes 30-day target timeframes for corrective actions.

Examples include:

- Implementing role-based access control (RBAC)
- Enforcing least-privilege access
- Strengthening endpoint security
- Implementing multi-factor authentication (MFA)
- Establishing firewall configuration standards
- Performing regular vulnerability scanning and penetration testing
- Maintaining documented security reviews and evidence
